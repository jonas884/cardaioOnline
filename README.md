# cardaioOnline

Este repositório contém um projeto didático desenvolvido como parte do curso de desenvolvimento fullstack, logo após a conclusão do módulo de HTML e CSS. O objetivo principal é aplicar e aprofundar conceitos fundamentais de front‑end de forma prática e progressiva.

## Tecnologias Utilizadas

- **HTML5**: Estrutura semântica das páginas, com elementos como `<nav>`, `<section>`, `<article>` e `<header>` para reforçar boas práticas de acessibilidade e organização do conteúdo. A escolha do HTML5 permite uma base sólida para futuros módulos (JavaScript, frameworks, etc.).

- **CSS3**: Estilos responsivos e modernos utilizando flexbox para layout (contêineres em linha e coluna). A decisão de explorar `flexbox` anticipe o uso de layouts flexíveis e adaptáveis, capacitando o aprendizado de grid e responsividade.

- **Arquivos estáticos**: Todas as páginas e estilos estão contidos localmente, o que simplifica a estrutura e facilita o versionamento com Git. Esta abordagem é intencional para focar em fundamentos antes de introduzir bundlers ou frameworks.

- **Imagens e recursos**: A pasta `imagens/` organiza os ativos visuais usados nas páginas, e os documentos em `requisitos/` registram inspirações de cores (`RefCores.txt`) e texto de roteiro (`RoteiroTexto.txt`).

Cada escolha tecnológica busca valorizar o aprendizado incremental: comece com o essencial (HTML e CSS puros), compre o fluxo de trabalho com controle de versão e preparação para evolução futura (JavaScript, back‑end, etc.). Estas decisões reduzem a complexidade inicial e mantêm foco no domínio dos blocos construtores da web.

## Estado do Projeto

O projeto encontra-se **em desenvolvimento**. As páginas atuais (`cardapio.html`, `index.html`, `atividade01.html` etc.) são protótipos que demonstram conceitos de layout, estilização e conteúdo estático. Há espaço para:

1. Tornar o cardápio dinâmico com JavaScript.
2. Adicionar responsividade para dispositivos móveis.
3. Integrar com serviço de back‑end para gerenciar itens e pedidos.
4. Reutilizar componentes via frameworks ou bundlers.
